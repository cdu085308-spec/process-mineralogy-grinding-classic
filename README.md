# 工艺矿物学磨矿分析系统 · 经典版 v1.0

这是独立保留的旧版手机端，不包含 2026 年 11 月升级新增的参数库页面、统一校验、回代校准、闭路磨矿、过程性评价和本地记录功能。

保留功能：

- 矿物组成输入与自动归一化
- Bond 能耗与磨矿参数分析
- 磨矿动力学模拟
- Rosin-Rammler 筛析拟合
- 解离度分析与结果报告

运行入口为 `app.py`，云端使用 Docker 部署。

## 云端部署

本目录可作为独立 GitHub 仓库使用，`render.yaml` 会创建免费的
`grinding-mineralogy-classic` Web Service。
